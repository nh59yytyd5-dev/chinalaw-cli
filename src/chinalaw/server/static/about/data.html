02 · 开始使用

从 软件发布页下载 wheel 并安装，再解压数据包。下面以 SQLite 包为例：

python -m pip install ./chinalaw-0.7.2-py3-none-any.whl

tar -xzf chinalaw-public-2026-09-30-sqlite.tar.gz
chinalaw --db ./chinalaw-public-2026-09-30-sqlite/library.db article 民法典 533

使用 JSON 包导入一个新库：

tar -xzf chinalaw-public-2026-09-30-json.tar.gz
chinalaw --db ./public-library.db sync --from-dir ./chinalaw-public-2026-09-30-json/laws

SQLite 包使用兼容索引布局，需要 SQLite 3.34+ 与 FTS5/trigram。遇到 SQLite 兼容问题，请用 JSON 包在目标机器导入。不要未经备份覆盖自己的工作库。

03 · 来源与致谢

官方来源：国家法律法规数据库。本项目保留每份记录的官方地址、核查时间与哈希，独立完成结构化、版本组织和检索索引。

感谢 lawtext/legal-data-docx 的原始 Word 文件收集与备份。本轮 2,476 份官方记录中，2,454 份原文件通过该仓库获取，22 份直接从官方源获取；另保留本项目公开维护的历史版本。

许可证分别说明。官方文件正文的性质依据《著作权法》第五条第一项；本项目可授权的代码和原创整理内容采用 Apache-2.0。原文镜像仓库未声明许可证，我们没有将它整体标为 MIT 或 CC0。下载包不附带第三方代码、README 或原始 Word 目录。

再分发时请保留来源、核查时间、原仓库链接和 NOTICE，标明你自己的修改。软件许可、数据性质和托管服务额度是三件不同的事。

04 · 范围与质量边界

  • 全国层级公开法规为主，含历史版本与“正文”条目；记录数不等于独立现行法律数量。
  • 本包由已审查的公开 JSON 重新构建，不是线上数据库备份；不包含认证、日志、私域规范或案件材料。
  • 2,476 份来源哈希与结构检查通过；20 份官方重下载抽样逐字节一致。抽样不等于逐份重新法律审定。
  • 缺少施行日期、废止日期或效力状态的记录保留待核信息。历史适用不能只看搜索排名。
  • 刑法等部分历史文本由项目维护，来源字段会明确标识；不能将其说成即时从官方网页抓取。
