A verifiable workflow

从你记得的条号开始。

让模型提出线索，让工具提供证据。

01 / 定位

已有条号，直接核对

知道大致法规与条号，就读取原文。法名不确定，再解析全称和候选；不必先搜索一遍学术术语。

02 / 核验

条号相同，版本可能不同

同时检查正文是否对题、施行日期、来源和案件时点。旧法条号在新版本中可能指向另一件事。

03 / 补齐

缺少依据时，再检索

用法条原文片段补查相关规定。近似结果明确标识，最终引用回到完整条文，而不是搜索摘要。

Choose your setup

离线优先，
也可以连接服务。

个人研究、持续集成或批量任务：下载 JSON 或 SQLite，在自己的电脑与服务器上使用。没有共享服务的调用额度，也不需要把研究查询发往托管服务器。

少量在线查询：托管 MCP 使用独立的公开库只读令牌，按需申请。下载文件由 GitHub Release 分发；这台服务器专注提供受控查询。

Sources matter

官方来源为国家法律法规数据库等公开机关网站。感谢 lawtext/legal-data-docx 的官方 Word 文件收集与备份工作。数据包保留出处、核查时间、来源哈希和上游致谢。
