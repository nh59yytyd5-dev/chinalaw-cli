# 资料库管理服务实施与验收记录

日期：2026-09-13。分支 `codex/library-admin-panel`，目标为 `0.6.0a1` 开发预览。
需求与原始范围见 [实施计划](ADMIN_PANEL_PLAN_20260913.md)，公开设计记录为
[issue #8](https://github.com/nh59yytyd5-dev/chinalaw-cli/issues/8)。

## 已实现

- P0/P1：可选服务依赖、schema 14 升级、只读访问边界、分页目录、冻结草稿、受管附件与持久任务。
- P2/P3：浏览器目录与全文、章节目次、来源原文、版本、完整差异、人工确认、核对标记和历史恢复预览。
- P4：单进程维护 worker、排队、取消、失败、重试、重启中断恢复；确认提交幂等与并发冲突检查。
- P5：本机配对/密码、服务器 HTTPS 配置、令牌与 OAuth、只读 REST/MCP HTTP、完整备份及事务性恢复。
- P6：离线静态构建、HTTP 与浏览器验收、独立安装包验证、Docker/Caddy 与跨平台 CI 门禁。

首次报错任务中的未提交改动已保留并继续完善。没有对实际使用中的用户资料库执行升级、导入或恢复。
所有开发验证使用临时数据库、仓库公开 fixtures 与明确虚构的材料。

## 重要实现选择

OAuth 使用官方 MCP SDK 的真实协议端点与单所有者持久授权，已验证 S256 PKCE、一次性授权码、刷新轮换、撤销、受众和私域权限。
因此首版不另行依赖 Keycloak；这不是第三方身份登录，也不提供多人协作。

恢复使用原 SQLite 文件内的写事务替换数据与重建索引，不替换仍可能被 CLI 打开的数据库 inode。
恢复预览后发生任何资料变更会触发冲突；失败回滚。附件先验证落盘，认证库始终独立。

公开/私域的法源类型、约束提示和状态沿用既有模型，没有新增法律分类或效力排序。
来源 hash、原件字节 hash 与规范化内容指纹分别保留原有或明确的新含义。

## 本机运行证据

环境：macOS 15.7.7 arm64、Python 3.12.13、FastAPI 0.141.1、Uvicorn 0.52.4、MCP SDK 2.2.0。
前端使用 React、TypeScript 和 Vite，构建后通过 FastAPI 提供静态文件，运行时不依赖 Node/CDN/模型。

| 验收 | 证据 |
| --- | --- |
| 目录与全文 | 浏览器读取 49 部公开法规、74 份版本记录、7,519 条当前条文；民法典 1,260 条可完整阅读和定位 |
| 人工导入 | 浏览器上传虚构私域文件，查看超过 120 字的全文、原文、完整差异、确认与重复导入；新内容不沿用旧核对标记 |
| 来源与恢复 | 原件下载、原件变更拦截、历史恢复预览、CLI 更新后不沿用旧来源附件标记 |

| MCP 协议 | 官方标准客户端在真实 TCP 上验证 legacy 2025-11-25 与 auto 2026-07-28；五个只读工具与私域隔离 |

| 安装与最终门禁 | 全量 Python 862 通过、32 既有跳过、1,704 子测试通过；Playwright 7 个流程通过；ruff 与 74 个公开 fixture 门禁通过 |

## 性能基线

`scripts/benchmark-admin` 使用临时库，先加载全部公开 fixtures，再加入 1,200 份虚构资料，合计 1,249 份资料、约 67.2 MiB 数据库。
下面是本机暖缓存下共享模块调用耗时，不包含网络和浏览器渲染时间，也不作为生产 SLA。

| --- | ---: | ---: | ---: |
| 公开基线目录 | 0.857 ms | 1.283 ms | 30 |
| 民法典全部正文 | 4.522 ms | 5.261 ms | 30 |
| 较大库分页目录 | 1.208 ms | 1.449 ms | 30 |

## 验证边界

商业 Work 客户端的账号权限、托管入口与实际登录未验证；只陈述已实际运行的 MCP/OAuth 协议兼容性。
当前本机没有 Docker/Podman 容器运行时，容器构建与启动通过仓库 CI 门禁检查，不能把直接 Python 启动等同于容器实测。
Starlette 1.6.0 的 TestClient 在 AnyIO 4.15.1 下有一条上游弃用提示，未影响运行；没有屏蔽该提示，已登记为 [issue #9](https://github.com/nh59yytyd5-dev/chinalaw-cli/issues/9)。

本版保持单所有者单 worker、手动确认和备份迁移范围。没有引入多人租户、自动双向同步、模型 OCR、自动法律判断或部署外部生产站点。
