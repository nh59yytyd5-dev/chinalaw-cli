## 分发与容量

GitHub Release承载wheel、源码、JSON/SQLite数据、manifest、质量摘要及SHA256SUMS，7个附件的远端大小与SHA-256均已验证。Oracle只承载静态文件和认证查询，不承载整库下载。

nginx按令牌5请求/秒、突发20，全站8并发查询；由于SNI转发隐藏客户端IP，不以回环IP区分使用者。MCP查询与REST读取受限，空闲SSE不占查询配额。40个无效令牌请求的有限突发中21次401、19次429，429均含Retry-After:2。

nginx配置检查通过后reload，保留原管理页、OAuth、MCP和其他站点。网页桌面/手机布局检查通过；受浏览器剪贴板权限限制时复制按钮显示手动复制提示。
