# 最小近似检索：评测与甲骨文部署验收

日期：2026-09-29。目标是精确优先、稀疏结果补充可解释的同条片段匹配，保留现有调用方式。

## 数据与方法

- 小库：58 部法规、8083 条条文。现有本地库；甲骨文线上副本也为此规模。
- 大库：2488 部全国层级法规、88750 条真实条文，从 chinalaw-ops 已整理的全国数据另建。
  此库仅作测试，没有导入生产，不把第三方数据或评测结果当成新的效力判断。
- 固定 30 条查询：20 条有目标条文的查询、8 个法规名称、2 个应落空的例子。
  目标条文按现有原文核对；这是定向回归集，不代表所有法律问题的检索准确率。
- 每条查询串行重复 3 次，前 20 条结果中检查目标排名；包含首次查询，不主动清操作系统缓存。
- 另测 7 个高频、长句、日期和过滤场景，每条 5 次。计时包含服务层打开数据库、检索、候选验证和排序，
  不包含公网 RTT。仅单请求串行测试，不代表高并发吞吐。
- `scripts/evaluate-search` 使用只读连接；查询集、候选片段和计时见 [step5-validation](step5-validation/)。

复现：

```bash
python scripts/evaluate-search --db <评测库> --output /tmp/result.json
python scripts/evaluate-search --db <评测库> --pool 2000 --output /tmp/pool-2000.json
python scripts/evaluate-search --db <评测库> --queries docs/research/step5-validation/stress.json --repeat 5 --output /tmp/stress.json
```

## 召回与排序

两套语料中，20 条有目标的查询仅精确通道命中 5 条；加近似后命中 18 条，全部位于前 5。
18 条支持的字面查询均召回；另外 2 条仍不支持，不能把 18/20 当成任意口语问题的成功率。
8 个名称候选全部排第一，均保持 `matched=false`，未自动用于取条。
“不安抗辩权”和“表现代理”最终都落空并提示改用法条原文用语。

明确限制：

- “约定的违约金超过造成的损失”：目标使用“过分高于”，本轮不补同义表达。
- “劳动者提前30日书面通知解除劳动合同”：本轮不把“30日”改为“三十日”。
- 查询完整片段不在正文中，或只在未入库材料中出现，近似检索不能替代原文核对。

评测驱动的修正：

1. 原来的名称打分使“民法点”在大库中将民法典排到第 5；加入连续公共片段信号后排第 1。
2. 原来的“表现代理”会匹配刑事诉讼法第 282 条中相隔较远的“表现”和“代理”。
   未分隔的 4 字以内短词现在只允许最多跨 2 字；“二倍的工资”仍命中，“表现……代理”不命中。
   用户显式分成多个词时仍按同条共现解释，不自动判断其法律含义。
3. 版本折叠测试覆盖未显式写入 work_id 的自动归组；近似结果不会向已有精确命中的作品补入另一版本。

## 性能

| 环境 / 场景 | 中位数 | P95 |
|---|---:|---:|
| Mac，8083 条，30 查询 | 11.09 ms | 20.38 ms |
| Mac，88750 条，500 候选 | 41.41 ms | 61.95 ms |
| Mac，88750 条，2000 候选 | 58.53 ms | 169.33 ms |
| 甲骨文 ARM，88750 条，500 候选 | 104.91 ms | 144.52 ms |
| 甲骨文 ARM，7 类压力查询 | 236.21 ms | 733.44 ms |
| 甲骨文 ARM，线上副本迁移后，8083 条 | 28.94 ms | 45.57 ms |

500 → 2000 没有新增目标命中或改善目标排名，所以保留 500。
甲骨文最慢场景是“国家，规定，管理，部门”，单次最大 736.92 ms。
这些结果覆盖全国层级约 9 万条，并未证明百万级地方法规或高并发性能；扩库时应复测。

## 兼容、交付与回滚

甲骨文 Python 的 SQLite 是 3.34.1，Mac 生成的 `contentless_delete` 索引不能直接搬过去。
评测库在副本上重建为既有的旧 SQLite 兼容索引后测试；正式库走应用自身迁移，不直接搬 Mac 数据库。
已验证生产库副本 v14 → v16 后的查询与候选结果。没有修改系统 SQLite、nginx 或认证凭据。
