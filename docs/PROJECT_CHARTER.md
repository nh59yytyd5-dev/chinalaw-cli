## 1. 一句话

`chinalaw-cli` 是面向 AI agent 法律工作流的本地规范来源内核。

它让 agent 在合同审查、法律备忘录、合规审查、制度核验等任务中，先调用本地 CLI 获取可追溯、可复核、可组合的规范依据，再继续分析和写作。

## 2. 出发点

大模型在法律场景中最危险的问题不是“不知道”，而是“说得像真的但依据不可靠”：

- 条号错位
- 引用旧法或废止规范
- 杜撰司法解释
- 来源不明，无法复核
- 把公司制度、客户要求误说成国家法

项目的任务不是生成最终法律意见，而是提供可靠 grounding。

## 3. 它是什么

- 一个可被 Codex、Claude Code、Cursor、Aider 或自建 agent 调用的 CLI。
- 一个本地 SQLite 规范来源库。
- 一个公开法规范、私域规范、事项约束的统一检索入口。
- 一个未来可接上游 adapter、skill、workflow 和 SDK 的底层内核。

## 4. 它不是什么

- 不是法律数据库公司的替代品。
- 不是法律问答机器人。
- 不是 GUI 产品。
- 不是把远程 MCP 包一层壳再转卖的服务。
- 不是替代律师判断的自动裁判系统。

## 5. 设计原则

### Agent-first

JSON 输出、退出码、错误语义、字段稳定性优先。任何能调 shell 的 agent 都能使用。

### Human-checkable

法律结果必须可被人复核。Markdown 输出、来源、状态、时间、哈希、warning 都是产品面。

### Local-first

合同、案件材料、公司制度、客户 instruction 往往不能上传远程服务。本地运行是默认形态。

### Open adapter

国家法律法规数据库、法院网站、国务院网站、商业 MCP、本地 docx / markdown 都可以是上游来源。但进入本地库前必须清洗、标注来源并计算 hash。

### Grounding only

CLI 提供依据和线索，不输出最终法律意见。

## 6. 规范来源模型

项目处理的是广义“规范来源”，不只是国家法条。

| 层级 | 示例 | 要求 |
|------|------|------|
| 公开法规范 | 法律、行政法规、司法解释、部门规章 | 最核心，必须可追溯 |
| 准规范 | 监管问答、交易所规则、行业规则 | 标明来源和效力边界 |
| 私域规范 | 公司制度、放款要求、HR 制度 | 标明制定主体和约束范围 |
| 事项约束 | 项目 memo、客户 instruction、案件策略 | 标明适用事项，不能泛化 |

统一接口不等于混同效力。agent 输出时必须说明依据层级。

## 7. 核心场景

最小核心场景是本地合同审查：

1. 用户让 Claude Code / Codex 执行合同审查 skill。
2. agent 识别争议点、事实时间、合同条款类型和私域约束。
3. agent 调用 `chinalaw search/get/article/fetch/norm/pack`。
4. `chinalaw` 返回可追溯规范依据。
5. agent 基于依据写审查意见，并标注来源、状态和不确定性。
6. 人类复核引用和判断。

## 8. 时间效力

时间效力是项目的重要方向，但 `chinalaw` 不应替代法律判断。

合理定位：

- agent 先意识到“事实时间可能影响适用法律”。
- CLI 提供当前规范、施行 / 废止日期、历史快照、关系线索和旧法 fetch 路径。
- 清洗后的文本进入同一结构。
- agent 阅读规则和 warning 后组织分析。

未来 `applicable` 应返回 grounding 信息，而不是最终结论。

## 9. 规范包

规范包短期定位为轻量复用层：

- 标签
- 收藏
- 问题域清单
- 工作流提示

它暂时不承担包生态、签名、远程安装源和团队分发。成员可以引用公开法条、私域规范和参考文本，但 pending reference 必须显式展示。

## 10. 与商业 MCP 的关系

商业法律数据库 / MCP 是潜在上游，不是竞争对象。

`chinalaw-cli` 的价值在本地侧：

- 缓存
- 清洗
- 来源追溯
- 私域规范融合
- 工作流复用
- agent 调用纪律

本项目可以提供轻量 MCP adapter，但它只是本地 CLI 内核的另一种调用壳：
不承载远程数据库、不绕过 cleaning / provenance、不把大量文档预塞进上下文。

## 11. 北极星

如果某个功能不能提升 agent 的 grounding、可追溯性、本地嵌入能力或规范层级区分，它就不是当前优先级。
